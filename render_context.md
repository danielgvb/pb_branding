# Render context / project rules
# Edit this file (on GitHub or in the app) to give the render agent context.
# Every line here is sent to the material assigner, the renderer and the QA checker.

- The SketchUp model is the final, approved design. The render is ONLY a material/finish visualization of it.
- Never change the camera, framing, perspective, walls, openings, ceiling, columns or floor layout.
- Never add, remove, move, resize or restyle any object. Furniture, fixtures and decorative items
  (pillows, vases, towels, lamps, screens, plants) stay exactly as modeled, with their modeled colors.
- Never add people, clothing, mannequins, products, logos, signage or text.
- Wall graphics / murals stay exactly as modeled.
- Lighting: keep the existing light sources; only add realistic shading, soft shadows and reflections.
- If something has no material swatch or is ambiguous, leave it exactly as modeled (just photoreal).
